# Goal

Create the initial monolithic repository layout for the project and set up a minimal continuous‑integration pipeline that enforces linting and dependency installation for both the `frontend/` and `backend/` sub‑projects.

---

# Scope

- Add top‑level directories: `frontend/`, `backend/`, `scripts/`, and `.github/workflows/`.
- Add a minimal `.gitignore` covering Node artefacts, build output, and OS temporary files.
- Initialise an empty Next.js TypeScript project in `frontend/` (no pages needed yet) and an empty Express TypeScript project in `backend/` (no routes yet).
- Configure ESLint and Prettier for both sub‑projects.
- Add a GitHub Actions workflow (`ci.yml`) that runs on each push, installs the correct Node version (v20), runs `npm ci` in both sub‑folders, and executes `npm run lint`.
- Ensure the CI passes on an empty repo.

---

# Acceptance Criteria

1. **Repository layout** – After merging, the repository root contains the directories `frontend/`, `backend/`, `scripts/`, and `.github/workflows/`.
2. **.gitignore** – The file excludes `node_modules/`, `dist/`, `.next/`, `out/`, `*.log`, and OS artefacts. `git status` shows no untracked generated files.
3. **Frontend scaffold** – `frontend/package.json` exists, `npm run dev` starts a Next.js dev server without errors, and `npm run build && npm run export` produces an `out/` folder.
4. **Backend scaffold** – `backend/package.json` exists, `npm run dev` starts an Express server (listening on a default port) without errors.
5. **ESLint + Prettier** – Both sub‑projects have `.eslintrc.json` and `.prettierrc` (or equivalent) and lint passes with `npm run lint`.
6. **GitHub Actions CI** – The workflow runs on push, uses Node 20, installs dependencies with `npm ci` for each sub‑project, and runs the lint command. The CI status badge on the repo shows **passing**.
7. **No secrets** – The CI workflow does not reference any secret values.

---

# Approach

1. **Create directories** – `mkdir frontend backend scripts .github/workflows`.
2. **Add .gitignore** – write a file covering Node, build artefacts, OS temp files.
3. **Frontend scaffold** – run `npx create-next-app@latest frontend --ts --eslint --src-dir` (skip adding pages for now). This creates a default ESLint config; adjust to include Prettier.
4. **Backend scaffold** – `mkdir backend && cd backend && npm init -y && npm i -D typescript ts-node-dev eslint prettier @typescript-eslint/parser @typescript-eslint/eslint-plugin && npx tsc --init`. Add a minimal `src/index.ts` that starts an Express server on port 8080.
5. **ESLint/Prettier config** – copy a shared config into both `frontend/` and `backend/` (or use root config with workspaces). Ensure `npm run lint` works in each.
6. **GitHub Actions workflow** – create `.github/workflows/ci.yml`:
   ```yaml
   name: CI
   on: [push, pull_request]
   jobs:
     lint:
       runs-on: ubuntu-latest
       strategy:
         matrix:
           dir: [frontend, backend]
       steps:
         - uses: actions/checkout@v3
         - name: Setup Node
           uses: actions/setup-node@v3
           with:
             node-version: '20'
         - name: Install deps
           working-directory: ${{ matrix.dir }}
           run: npm ci
         - name: Lint
           working-directory: ${{ matrix.dir }}
           run: npm run lint
   ```
7. **Commit & push** – create a branch `agent/phase-1-scaffold-ci-v3`, add all files, commit with a clear message, push, and open a PR.
